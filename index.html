About the Project

This project demonstrates how Real-Time Operating System (RTOS) scheduling algorithms can be applied to smart traffic management at a single intersection.

Users can configure traffic tasks (normal vehicles & emergency vehicles), run simulations, and compare the efficiency of Round Robin vs Earliest Deadline First (EDF) algorithms using interactive Gantt charts and performance metrics like average waiting time, turnaround time, deadline misses, and intersection utilization.

Built with HTML, CSS, and JavaScript — entirely client-side with no backend required.

The Ambulance Problem in Traffic Systems

In real traffic scenarios, we have a mix of normal vehicles (cars, bikes) and urgent vehicles (ambulances, fire trucks 🚑🚒).

The Challenge: How do we schedule traffic lights so urgent vehicles don’t wait too long, while ensuring normal traffic flow continues smoothly?

  • 🚑 Emergency Vehicle Delay: Round Robin (RR) gives equal time slices to all lanes. This forces the ambulance to wait in line. EDF solves this by giving the ambulance the highest priority (earliest deadline), triggering an immediate green signal.
  • ⏳ Unnecessary Waiting Time: Empty or low-traffic lanes still get a fixed time slice in RR. EDF dynamically skips or demotes inactive lanes, reducing overall wait times.
  • 🚗 Traffic Congestion: RR ignores lane load and burst length, so busy lanes stay crowded. EDF helps clear critical tasks efficiently.
  • ⚖️ Priority & Efficiency: Standard RR has no priority system, leading to inefficient fixed time allocations and low system efficiency. EDF dynamically adjusts based on deadlines/urgency.

This simulator effectively demonstrates how real-time scheduling logic (EDF) outperforms standard fair-share algorithms (RR) in critical situations.
